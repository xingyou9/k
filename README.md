# 计算机网络技术2604班 · 智能课表

> iOS 27 液态玻璃风格的单文件课表网页，手机 / 电脑自适应。

**在线访问：** <https://xingyou9.github.io/kebiao/>

## 功能

| 模块 | 说明 |
|---|---|
| 课表视图 | 桌面端六列表格；手机端卡片 / 表格双模式 |
| 单双周 | 依据学期起始日自动推算周次，单双周课程自动区分「本周上 / 不上」 |
| 今日视图 | 时间轴 + 红色「现在线」+ 上课倒计时 + 下一上课日提示 |
| 统计 | 学时环图、每日分布、教师授课排行、空闲时段 |
| 交互 | 搜索、收藏、分类筛选、课程详情、地点与备注记录 |
| 其他 | 深浅色主题、打印 / 存 PDF、复制文本、导出 .ics 日历 |

## 数据说明

共 10 门课、8 位教师，依据班级纸质课表录入。原表中星期三、星期四第 5–8 节为黄色底纹待定块，页面内点击可自助补录；理论课与实训课地点留空可自行填写（保存在浏览器本地）。

## 部署

纯静态单文件，`index.html` 直接由 GitHub Pages 托管，无构建步骤、无外部依赖。
