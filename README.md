## 功能

| 模块 | 说明 |
|---|---|
| 课表视图 | 电脑端六列表格（时间 / 节次 / 课程 / 教师 / 理论课地点 / 实训课地点）；手机端卡片、表格双模式 |
| 上课时间 | 节次列同时标注**开始与结束时间**（如 08:10 / 09:40），手机卡片与今日时间轴同样显示起止时刻 |
| 单双周 | 依据学期起始日自动推算周次，单双周课程自动区分「本周上 / 不上」并给出暗色标注 |
| 今日视图 | 时间轴 + 红色「现在线」+ 下一上课日提示 |
| 下节课倒计时 | **时 : 分 : 秒** 大号数字，每秒刷新；上课中显示「正在上课」与下课时间，可跨天向后查找最多 14 天 |
| 学时进度 | **已上 / 剩余学时**双向进度条，统计页给出各门课明细进度，今日页给出迷你进度条 |
| 统计 | 已上 / 剩余 / 本周学时等 6 张指标卡、学时占比环图、每日分布柱状图、教师授课排行、空闲时段 |
| 作息时间 | 设置页内置学校 9 段作息表（第一节 → 晚自习），各节次上课时间可自行修改 |
| 交互 | 搜索、收藏、分类筛选、课程详情、理论 / 实训地点与备注记录 |
| 其他 | 深浅色主题、打印 / 存 PDF、复制文本、导出 .ics 日历 |
| 移动端 | 支持「添加到主屏幕」当 App 用（已配置 PWA manifest） |

### 学时计算口径

- 一个时段（两节连上）= **2 学时**。
- 单双周课程只统计**实际开课的周次**（如「创新创业」第 4-16 周单周，实际 6 次课 = 12 学时）。
- 以每次课的**下课时间**为界判定是否「已上」，整学期共 **360 学时**。
- 学期起始日设为 `2026-08-24`，2026-10-05 起为第 7 周。

## 使用提示

- 手机打开后建议 **添加到主屏幕**，即可全屏当 App 使用。
- 地点、备注、收藏等个人数据保存在**浏览器本地**，换设备不会同步。
- 「设置」页可修改学期起始日与各节次时间，全站统计、倒计时与学时进度会同步更新。

## 部署

纯静态单文件，`index.html` 由 GitHub Pages 托管，无构建步骤、无外部依赖。

更新方式：修改本地课表 HTML 后执行 `python deploy/push-to-github.py`。
