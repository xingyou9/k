## 功能

| 模块 | 说明 |
|---|---|
| 课表视图 | 电脑端六列表格；手机端卡片 / 表格双模式 |
| 单双周 | 依据学期起始日自动推算周次，单双周课程自动区分「本周上 / 不上」 |
| 今日视图 | 时间轴 + 红色「现在线」+ 上课倒计时 + 下一上课日提示 |
| 统计 | 学时环图、每日分布柱状图、教师授课排行、空闲时段 |
| 交互 | 搜索、收藏、分类筛选、课程详情、地点与备注记录 |
| 其他 | 深浅色主题、打印 / 存 PDF、复制文本、导出 .ics 日历 |
| 移动端 | 支持「添加到主屏幕」当 App 用（已配置 PWA manifest） |

## 数据说明

共 **10 门课、8 位教师**，依据班级纸质课表录入：

| 星期 | 节次 | 课程 | 教师 |
|---|---|---|---|
| 一 | 5-6 / 7-8 | 信息技术 / 体育与健康 | 付杰 / 张鹏 |
| 二 | 7-8 | 创新创业（单周）/ 心理健康教育（双周）· 4-16 周 | 魏淑苑 / 王金琦 |
| 三 | 1-2 / 3-4 | 应用数学 / 思想道德与法治(4-12周)、劳动教育(13-16周) | 卢晓冉 / 宋丽丽 |
| 四 | 1-2 | 形势与政策(10-13周)、国家安全(14-15周) | 蔡宁 |
| 五 | 3-4 | 实用英语 | 陈雨琳 |

原表中**星期三、星期四第 5–8 节**为黄色底纹待定块，页面内点击可自助补录；理论课与实训课地点留空，可自行填写（保存在浏览器本地）。

## 使用提示

- 手机打开后建议 **添加到主屏幕**，即可全屏当 App 使用。
- 地点、备注、收藏等个人数据保存在**浏览器本地**，换设备不会同步。
- 「设置」页可修改学期起始日与各节次时间，全站统计与倒计时会同步更新。

## 部署

纯静态单文件，`index.html` 由 GitHub Pages 托管，无构建步骤、无外部依赖。

更新方式：修改本地课表 HTML 后执行 `python deploy/push-to-github.py`。
